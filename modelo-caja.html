Modelo de caja en CSS

Regresar

1. Introduccion teorica

El modelo de caja en CSS explica como se organiza el espacio de los elementos HTML. Esta formado por cuatro partes: contenido, padding, border y margin.

2. Ejemplos de cajas en css

Ejemplo 1: Width y height

Permiten establecer el ancho y el alto de un elemento.

Contenido

width: 200px; height: 60px;

Ejemplo 2: Padding

Agrega espacio entre el contenido y el borde.

Texto con padding

padding: 20px;

Ejemplo 3: Border

Permite agregar un borde alrededor del elemento.

Caja con borde

border: 3px solid blue;

Ejemplo 4: Margin

Agrega espacio exterior alrededor del elemento.

Caja con margen

margin: 25px;

Ejemplo 5: Box-sizing

Permite controlar como se calcula el ancho y alto total de una caja.

Caja de 200px

box-sizing: border-box; width: 200px; padding: 20px; border: 5px solid green;
