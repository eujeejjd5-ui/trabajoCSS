1. Teoria de Bootstrap

Bootstrap es un framework que facilita el diseño de paginas web. Incluye clases preparadas para crear botones, colores, margenes, contenedores y otros elementos. Se puede incluir mediante un enlace CDN dentro de la etiqueta head del documento HTML.
